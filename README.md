# MapleDiscordBridge - KuroMS Web Edition

Cầu nối điều khiển và tự động hóa game **KuroMS Web** (HTML5 Canvas/WebGL) qua **Discord Slash Commands** và **Chrome DevTools Protocol (CDP)**.

---

## 📥 Tải Về Nhanh

* **[👉 Bấm vào đây để tải MapleDiscordBridge_Web.zip](https://raw.githubusercontent.com/dutch25/MapleBridgeWeb/main/MapleDiscordBridge_Web.zip)** (Gói nén file `.exe` đã build sẵn).
* Sau khi tải về: Giải nén và chạy file `MapleDiscordBridge_Web.exe`.

---

## 🚀 Tính Năng Chính

* **Điều khiển ngầm qua Chrome DevTools Protocol (CDP port 9222):** Không chiếm chuột/bàn phím, tab sang cửa sổ khác hoặc chat thoải mái nhân vật vẫn tự động đánh và di chuyển.
* **Tự động đánh ngầm (Auto-Attack):** Chế độ `hold` thông minh, chống mất phím khi unfocus.
* **Auto-Buff 3 tầng:** Điều phối macro chuẩn, tự động khôi phục nhịp đánh ngay sau khi cast skill.
* **Lệnh Discord:** `/reply`, `/bot`, `/buff`, `/screen`, `/kill`, `/status`, `/anchor`.
* **Lệnh `/kill` an toàn:** Chỉ đóng trình duyệt KuroMS port 9222, tuyệt đối không động chạm cổng 9223 (KuroMarketTracker) hay client game khác. Hiển thị rõ danh tính người kill.
* **Console trực quan:** Toàn bộ log console đều có mốc thời gian `[HH:MM:SS]`.
